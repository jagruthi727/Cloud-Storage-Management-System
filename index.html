AUTOMATIC PLACEMENT

Storage tiers

3 classes
♨

Hot storage

Frequently accessed data

  • Low latency
  • Higher cost
  • Fast retrieval
AWS S3 Standard
▤

Warm storage

Occasionally accessed data

  • Balanced cost & speed
  • Medium latency
  • Moderate retrieval
AWS S3 Standard-IA
▣

Cold storage

Rarely accessed data

  • Lowest cost
  • Higher latency
  • Long-term archive
AWS S3 Glacier
